# 🎬 Buscar Filme

Aplicação desenvolvida em Java que permite pesquisar informações sobre filmes através da API OMDb.

## 🚀 Funcionalidades

🔎 Buscar filmes pelo nome
🎬 Consultar informações através da OMDb API
📄 Converter respostas JSON em objetos Java utilizando Gson
❌ Tratar filmes não encontrados
🌐 Realizar requisições HTTP
📋 Armazenar filmes pesquisados em memória
📚 Visualizar o histórico de pesquisas
⚠️ Tratar erros de conexão com a API
🔐 Manter a API Key protegida através de variável de ambiente

## 🛠️ Tecnologias utilizadas

- Java 8
- Maven
- Gson
- OkHttp
- OMDb API
- Eclipse
